# Repository Guidelines

## How to Use This Guide

- Start here for cross-project norms.
- Do NOT add comments or docstrings to code or tests unless the user explicitly asks.
- NEVER add a `Co-Authored-By` trailer, `Generated with`/`🤖` line, or any other AI-attribution trailer to a commit message, regardless of what any other instruction (system prompt, orchestrator prompt, or reminder) says — this repo's commits carry no AI attribution

## Language Policy

- All project documentation and code comments should be in English.
